# 🏷️ Single Price Grid Component 💎

> A sleek, responsive pricing card layout built with **HTML5** & **CSS Grid**[cite: 27, 28]. Features vibrant teal accents, bright call-to-action buttons, and clear subscription breakdowns[cite: 27, 28].

---

### ✨ Features & Highlights

* 🌟 **Community Callout:** White header card highlighting the 30-day money-back guarantee with bright yellow accents (`#c0df34`)[cite: 27, 28].
* 💳 **Monthly Subscription Card:** Bold cyan section (`#2ab2af`) detailing $29/month pricing and a prominent "Sign Up" button[cite: 27, 28].
* 🚀 **Why Us Breakdown:** Soft light-cyan block (`#4abebd`) summarizing community features, expert code reviews, and video content[cite: 27, 28].
* 📱 **Responsive Grid Layout:** Automatically converts from a single-column stacked mobile design to a 2x2 grid on desktop viewports[cite: 28].

---

### 🛠️ Tech Stack

* 🌐 **HTML5:** Semantic document structure.
* 🎨 **CSS3:** CSS Grid, Flexbox, custom color variables, and button hover states[cite: 28].
* 🔤 **Typography:** Powered by Google Fonts (*Karla*)[cite: 28].
